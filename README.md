# SciTrack - Complete Research & Lab Hub for Science Students

SciTrack is an all-in-one laboratory assistant built specifically for undergraduate and graduate science students across biology, biochemistry, chemistry, and molecular genetics.

## Features Included (All 6 Core Modules):
1. **Lab Tasks Queue**: Prioritized checklist for bench procedures, buffer preps, and instrument calibrations with real-time completion tracking.
2. **Personalized Lab Notebook**: Structured experiment logging (Hypothesis, Observations, Conclusions) with one-touch scientific unit symbols (°C, µL, mL, OD₆₀₀, pH, rpm, λ=), instant search, and formatted export.
3. **Step-by-Step Protocol SOPs & Live Timers**: Interactive protocol checklist with progress tracking, built-in countdown timers, audio finish chimes, and instant cross-logging to the Lab Notebook.
4. **Solutions & Reagent Recipe Book**: Dynamic batch volume scaler (100 mL to 2.0 L) that recalculates ingredient masses to 3 decimal places for balance weighing, plus one-click task scheduling.
5. **Science & Dilution Calculator**: Instant C₁V₁ = C₂V₂ dilution solver, Molarity-to-Mass calculator with quick molecular weight presets (NaCl, Tris, EDTA, KCl, Glucose), and two-way unit converters.
6. **Failed Experiment Log**: Systematic troubleshooting tool that categorizes setbacks (Contamination, Reagent, Protocol, Equipment, Anomaly), documents root causes & lessons learned, and auto-generates retry corrective actions into the Lab Tasks queue.

## Mobile & APK Support:
SciTrack is mobile-responsive and Progressive Web App (PWA) ready. Read HOW_TO_CREATE_APK.md inside this package for instructions on installing it directly on your Android phone or generating a standalone .apk file.
